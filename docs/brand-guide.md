# PracticeNudge Brand Guide

## Wordmark

PracticeNudge uses a text-only wordmark (no icon). The name is written as one word with capital P and N: **PracticeNudge**

### Canva/Figma Prompt Options

**Option A — Clean Professional:**
```
Create a wordmark logo for "PracticeNudge". Use Inter or DM Sans font, semi-bold weight. 
Navy blue (#1e3a5f) text on white background. Clean, minimal, no icon. 
Professional accounting/finance feel. Kerning slightly tightened.
```

**Option B — Friendly Modern:**
```
Create a wordmark logo for "PracticeNudge". Use Plus Jakarta Sans or Outfit font, medium weight.
Dark slate (#1e293b) for "Practice", teal accent (#0d9488) for "Nudge". 
No icon. Approachable but professional. Suitable for B2B SaaS.
```

**Option C — Bold Confident:**
```
Create a wordmark logo for "PracticeNudge". Use Instrument Sans or Satoshi font, bold weight.
Deep navy (#0f172a) text. Subtle rounded corners feel. 
No icon, no gradients. Trustworthy, established, UK professional services.
```

## Tone of Voice

- Professional but approachable
- Direct, not salesy
- UK English spelling (colour, organisation, practise as verb)
- Avoid: "AI-powered", "revolutionary", "game-changing"
- Use: "simple", "clear", "built for", "no more guessing"

## Logo Usage

- Minimum size: 120px wide (digital)
- Clear space: height of "P" on all sides
- Dark backgrounds: white text
- Light backgrounds: navy text
- Never: stretch, rotate, add effects, change colours

## Favicon

- 32x32 and 16x16 PNG
- Use "PN" lettermark in navy on white, or white on navy
- Simple, legible at small sizes
